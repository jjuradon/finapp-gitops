# Security Policy

## Supported Versions

Only the latest version of FamilyFinance is actively supported with security updates.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it immediately by opening a private GitHub Security Advisory or contacting the maintainers directly. Do not report security vulnerabilities via public issues.
