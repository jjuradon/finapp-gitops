# ADR-004: Cross-cutting services (ingestion, notification, sync) deferred to Phase 2

- **Date:** 2026-05-17
- **Status:** Accepted
- **Deciders:** Architecture committee

## Context
We need to prioritize which services are built in Phase 1 (Home Lab).

## Decision
Cross-cutting services are deferred to Phase 2 (Cloud-Ready).

## Consequences
They are not needed for a home lab environment and add operational complexity before the core is stable.

## Alternatives Considered
Build all services upfront - Rejected because it violates the principle of deferring distributed systems complexity.
