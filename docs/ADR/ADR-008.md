# ADR-008: WatermelonDB for mobile offline

- **Date:** 2026-05-17
- **Status:** Accepted
- **Deciders:** Architecture committee

## Context
We need an offline storage strategy for the mobile application.

## Decision
We will use WatermelonDB.

## Consequences
SQLite-backed, reactive, React Native native; sync protocol designed specifically for offline-first scenarios.

## Alternatives Considered
AsyncStorage (too simple, lacks reactivity and robust sync), Realm (heavier, historically harder to integrate with certain Expo versions).
