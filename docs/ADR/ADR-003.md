# ADR-003: Planning module keeps budgets + goals together

- **Date:** 2026-05-17
- **Status:** Accepted
- **Deciders:** Architecture committee

## Context
We need to decide how to bound the context of planning features (budgets and saving goals).

## Decision
The planning module will keep budgets and goals together.

## Consequences
Shared period-reset and notification trigger logic. There is no independent scaling need yet.

## Alternatives Considered
Separate budget-service and goal-service - Rejected as it would require distributed transactions for shared logic unnecessarily early.
