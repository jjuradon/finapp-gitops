# ADR-006: RabbitMQ over Kafka

- **Date:** 2026-05-17
- **Status:** Accepted
- **Deciders:** Architecture committee

## Context
We need to select a message broker for async communication.

## Decision
We will use RabbitMQ (3.13) with aio-pika.

## Consequences
Simpler to operate at home-lab scale; sufficient throughput for personal finance workloads.

## Alternatives Considered
Kafka - Better at high-throughput event streaming, but operationally much heavier.
