# ADR-007: TimescaleDB extension (not a separate engine) for analytics

- **Date:** 2026-05-17
- **Status:** Accepted
- **Deciders:** Architecture committee

## Context
We need to support time-series queries for analytics.

## Decision
We will use the TimescaleDB extension on our primary PostgreSQL 16 instance.

## Consequences
Keeps everything in a single PostgreSQL instance in Phase 1, allowing time-series queries on spending data without extra infrastructure.

## Alternatives Considered
InfluxDB, separate Postgres instance - Rejected to avoid managing multiple database engines in Phase 1.
