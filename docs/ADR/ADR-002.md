# ADR-002: FastAPI over Flask / Django

- **Date:** 2026-05-17
- **Status:** Accepted
- **Deciders:** Architecture committee

## Context
We need to select a primary web framework for the backend services.

## Decision
We will use FastAPI (>=0.115).

## Consequences
ASGI support, async-native execution, tight integration with Pydantic v2, and automatic OpenAPI documentation generation.

## Alternatives Considered
Flask (no async natively, harder to scale with async workloads), Django (too heavy for our modular needs).
