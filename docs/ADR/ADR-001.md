# ADR-001: Start as modular monolith

- **Date:** 2026-05-17
- **Status:** Accepted
- **Deciders:** Architecture committee

## Context
We need to decide the initial architecture layout for the backend. Microservices introduce operational complexity, while a monolithic approach may become difficult to scale in terms of development velocity later.

## Decision
We will start with a modular monolith architecture.

## Consequences
Home lab deployment; avoid distributed systems overhead before it's needed. This simplifies initial deployment and local development (one process), while enforcing strict boundaries internally through module boundaries so that we can split out microservices later if necessary.

## Alternatives Considered
Full microservices from day one - Rejected due to overhead at this early stage.
