# ADR-005: React Native + Expo for mobile

- **Date:** 2026-05-17
- **Status:** Accepted
- **Deciders:** Architecture committee

## Context
We need to select a framework for the mobile application.

## Decision
We will use React Native with Expo (SDK 51+).

## Consequences
Shared logic with web client (TanStack Query, Zustand patterns). Expo managed workflow reduces native toolchain friction significantly.

## Alternatives Considered
Flutter, native iOS/Android - Rejected due to lack of shared ecosystem with the React web client.
